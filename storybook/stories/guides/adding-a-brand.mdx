# Adding a brand

Example: how the Ascendiun brand was added (follow the same steps for a new brand).

1. **Tokens:** fill `styles/themes/ascendiun.css` with the brand's values for the tokens that differ from
   Blue Shield (colors, fonts, radii, shadows …). Self-hosted fonts go in `fonts/` with their
   `@font-face` rules in the theme file.
2. **Scripts:** in `THEMES` (`scripts/scripts.js`), set `css: true`, whether it uses the shared Fieldwork fonts
   (`webFonts`), whether OneTrust runs, `favicon: '/favicons/ascendiun.png'` (add the icon to `favicons/`) and
   `logos` (the brand logo shown instead of the careers logo, an icon in `icons/`).
3. **Content:** create the `/ascendiun/` folder in Document Authoring and add a row to `/metadata`:
   `URL` `/ascendiun/**`, `theme` `ascendiun`. Preview and publish the sheet.
4. **Library:** add the value to the `theme` row of the `options` tab in `/tools/library/blocks`, so it
   appears in the Metadata slash menu.
5. **Storybook:** the toolbar already lists Ascendiun. A new brand needs an entry in `globalTypes.brand` in
   `storybook/.storybook/preview.js`. Then review **Foundations** and **Blocks** with the new brand.
6. **Lint:** `npm run lint` (raw values are allowed only in the theme file).

The header and footer are shared: the new theme recolors them through the header, footer and button
tokens. If the logo needs another color on the brand's background, set `--nav-logo-filter`.
