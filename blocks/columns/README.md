# columns

Custom **columns** block. Purpose: Side-by-side columns of content; with 'alternating', image/text rows whose sides alternate.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per line of columns, one cell per column. With 'alternating': each row has a media cell (image, optionally followed by a youtube.com/watch link for a video) and a text cell (optional H3, paragraphs, lists, links); author the cells in either order.

## Supported variations

| Variation | Option class |
| --- | --- |
| Alternating | `alternating` |
