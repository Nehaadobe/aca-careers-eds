# table

Custom **table** block. Purpose: Tabular data, or a bordered callout box when the table has a single cell.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one block row per table row, one cell per column; the first row is the header unless the no-header class is set. A single-cell block renders as a callout.

## Supported variations

No variations.
