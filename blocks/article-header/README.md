# article-header

Custom **article-header** block. Purpose: Blog story header: category links, title, date, byline with share links, then a full-width hero image or video.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Auto-built on Template = blog-article pages (scripts.js buildAutoBlocks), not authored. Key/value rows Role, Topic, Publication Date, Author, Author Title from page metadata; a row with the first H1; a row with the hero that directly follows the H1 (picture paragraph or Embed (video) block); a row with a nested share block.

## Supported variations

No variations.
