# share

Custom **share** block. Purpose: Social share links for the current page.

## Authoring (Document Authoring)

Model: `standalone`

Single block table with one cell: the label shown before the icons ("Share"); leave it empty for the default label. Auto-built inside the article-header on blog-article pages. The LinkedIn, Facebook and X icons are drawn by share.js when the page renders, so Document Authoring shows only the label cell.

## Supported variations

No variations.
