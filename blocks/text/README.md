# text

Custom **text** block. Purpose: Story text with an alignment that default content cannot carry, as the source's inline `text-align` (the right-aligned intern sign-offs on /blog/reflections-from-our-2026-interns).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one cell (or several) with the paragraphs, headings or lists to align, e.g. `Text (right)` with "-Jesse Chen, IT Applications, Stellarus". Place it between story paragraphs; it is spaced like default content.

## Supported variations

| Variation | Option class |
| --- | --- |
| Right-aligned | `right` |
| Centered | `center` |
| Box: the light-blue panel (source .simplebox) | `box` |
| Float left: a third of the column wide, the photo and text that follow sit beside it; full width below 768px (e.g. `Text (box, float-left)`, the pull quote on the Joe Sabo story) | `float-left` |
