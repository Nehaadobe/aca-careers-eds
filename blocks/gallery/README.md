# gallery

Custom **gallery** block. Purpose: Edge-to-edge row of images that open full size in an accessible lightbox.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per image; the cell holds the image, optionally a link to the full-size file (wrapping the image or as a separate link) and an optional caption paragraph.

## Supported variations

No variations.
